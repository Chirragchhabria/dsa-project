# Security policy

This project is a defensive, local alert-analysis prototype. It does not ingest untrusted data as a network service, and it does not make production security decisions. Do not put secrets or private logs in issues, pull requests, or sample datasets.

For a vulnerability in the parser or CLI, open a private GitHub security advisory for the repository if that feature is available. Otherwise, contact the maintainers privately through their GitHub profiles. Include a minimal synthetic reproducer and the affected commit or release. Avoid publishing exploit details before maintainers have had a chance to investigate.
